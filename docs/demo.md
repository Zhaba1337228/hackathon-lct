# Живая демонстрация

Сервис принимает GeoJSON без ручного изменения геометрии, показывает рост общей сети на карте и выгружает проверенные варианты. Для показа нужны Docker Desktop и Node.js 18+.

## Запуск

Из корня проекта:

```powershell
docker compose up -d --build
```

Откройте `http://localhost:8080/` (либо порт из `APP_HOST_PORT`, например 8100), загрузите отдельно полученный конкурсный GeoJSON или свой набор WGS84, выберите видимую область и нажмите «Рассчитать трассы». Для воспроизведения конкурсного сценария файл можно поместить в `inputs/ТЗ/Датасет скорректированный.geojson`; эта папка исключена из публичного Git. Для показа общих стволов перед запуском Compose включите `conservative-group-trunks` по [README](../README.md). В этом режиме зелёная линия показывает одно уже проверенное дерево; оранжевые линии и метки — проверяемые попытки. По ссылке `http://localhost:<порт>/?job=<jobId>` можно вернуться к расчёту, пока результат хранится сервером.

Автоматический сценарий запускается командой:

```powershell
node scripts/demo.mjs
```

Скрипт загружает скорректированный конкурсный GeoJSON, берёт bbox через `/view/extent`, ожидает завершения задания и сохраняет `artifacts/demo/heat-network-variants.geojson` и `.summary.json`. Другой вход и путь экспорта принимаются двумя аргументами. `HEAT_DEMO_BASE_URL`, `HEAT_DEMO_POLL_MS`, `HEAT_DEMO_TIMEOUT_MS` задают адрес, период опроса и тайм-аут. Старый файл в `artifacts/demo` нельзя выдавать за результат новой версии, пока не прошёл новый расчёт.

## Что показать

1. На исходном наборе: 144 объекта, из них 17 точек подключения. Показать подложку, здания, существующую сеть, ТЭЦ и точки.
2. Живой рост ствола и отводов; отличие проверенного дерева от непринятой попытки.
3. Сводку до трёх вариантов: подключённые ID, все неподключённые `unconnectedTargetIds`, диагностическое подмножество `unsearchedTargetIds`, стоимость строительства, штраф, длину и оценку.
4. Экспорт `/api/jobs/{jobId}/export`: один GeoJSON FeatureCollection с новыми трубами, камерами, техническими узлами и `variant_summary`. Исходные объекты доступны отдельно через `/view`.

Актуальный полный API-прогон v28 (2026-09-29) дал 14/17 в одном варианте за 664,175 с. Строительство — 333 378 137,83 ₽, штраф за цели 2, 5 и 10 — 338 995 000 ₽, общий расчёт — 672 373 137,83 ₽. Экспорт и формула проверены `scripts/report_job.mjs`; геометрические ограничения применяет серверный валидатор. Для просмотра готового результата: [карта на локальном сервисе](http://localhost:8099/?job=fb5bbf47-ecb4-4de8-8edd-46c961ba36b4), пока работает контейнер `lct-submission-v28`. Полная конкурсная приёмка 17/17 пока не подтверждена; файлы — в [комплекте сдачи](../submission/README.md).

Частичный поиск не доказывает техническую невозможность подключения. Выданные трассы — двумерная предварительная модель, а не гидравлический расчёт или рабочий проект.
