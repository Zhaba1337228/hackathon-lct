# Материалы выступления

Редактируемые слайды: [PPTX](../submission/heat-network-routing.pptx). Версия для просмотра: [PDF](../submission/heat-network-routing.pdf). Девять слайдов рассчитаны на 6–8 минут; изображение сети построено из конкурсного GeoJSON и проверенного полного API-экспорта v28. Генератор — `scripts/build_submission_deck.py` (python-pptx и Pillow). Частичный статус 14/17 указан прямо.

1. **Задача.** Новое здание нельзя подключать изолированно: выбор первой трубы влияет на остальные врезки и цену всего дерева.
2. **Сложность.** Геометрия города, топология сети и экономика должны учитываться вместе.
3. **Поток.** 144 объекта, 17 целей и 85 контуров ОКС → кандидаты врезки → коридоры → независимая проверка → до трёх вариантов. Длины считаются в EPSG:32637, экспорт — WGS84.
4. **Общий ствол.** Секции зданий, допустимый коридор, отводы от уже построенной трубы и ограниченный просмотр следующих целей. Общий участок оплачивается один раз, а изменения расхода, ДУ и камер пересчитываются.
5. **Проверки.** Валидатор заново проверяет геометрию, отступы, специальные проходы, связность, узлы и диаметр. Отклонённые варианты не выдаются.
6. **Факт на карте.** Полный API-прогон v28 подключил 14/17. Экспорт проверен по ID, топологии, конечным точкам, суммам и согласованию с API; геометрические нормы проверяет серверный валидатор.
7. **Экономика.** За каждую точку, отсутствующую в варианте, начисляется `100 000 000 + 500 000 × flow_tph` ₽. `unsearched` описывает неполный поиск, но не исключает штраф. В v28 за три точки начислено 338 995 000 ₽.
8. **Три оставшиеся цели.** По 2/5/10 показать свободный просвет против требуемого отступа, обязательный ближайший ввод из §2.2 приложения, запрет повторного пересечения ОКС из таблицы 2 и замкнутый двор цели 5. Другие фасады локально свободны, но не соответствуют буквальному правилу ближайшей границы. Основное ТЗ, §2.9, утверждает подключаемость всех зданий, поэтому нужен ответ организаторов; ненайденный маршрут не объявлять невозможным.
9. **Статус.** 14/17 — полный API-результат; 17/17 — конкурсный критерий, пока не подтверждён. Для целей 2, 5, 10 подготовлен вопрос организаторам о ближайшей границе собственного ОКС.

Живой показ проводить по [сценарию](demo.md). Проверенный экспорт v28 хранится только локально и не включён в публичный Git вместе с конкурсными данными; его можно повторно получить через API после собственного прогона. Прежний `artifacts/demo/heat-network-variants.geojson` относится к более ранней версии.
