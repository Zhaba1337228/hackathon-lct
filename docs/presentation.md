# Материалы выступления

Редактируемые слайды: [PPTX](../submission/heat-network-routing.pptx). Версия для просмотра: [PDF](../submission/heat-network-routing-lct2026.pdf). Тринадцать слайдов собраны из официального шаблона ЛЦТ 2026 и рассчитаны на 7–9 минут; изображение сети построено из конкурсного GeoJSON и проверенного полного API-экспорта v28. Генератор — `scripts/build_lct_template_deck.py` (python-pptx; для пересборки нужен оригинальный `ЛЦТ2026 Шаблон презентации.pptx`, который не публикуется в репозитории). Частичный статус 14/17 указан прямо.

1. **Титул.** Команда «БарэвЗэс», задача ДИТ и назначение сервиса.
2. **Коротко о решении.** Общая сеть для группы зданий, варианты на карте и геометрическая проверка.
3. **Команда.** Четыре участника РТУ МИРЭА; роли, контакты и специальность указаны на слайде.
4. **Почему задача.** Врезка в ближайшую трубу может испортить цену и охват всей сети.
5. **Суть решения.** Данные, поиск коридоров, независимый валидатор, сравнение вариантов.
6. **Проблема и данные.** 144 объекта, 17 целей и 85 контуров ОКС.
7. **Пять этапов расчёта.** Ввод → группы → общий коридор → проверка → оценка.
8. **Общий ствол и отводы.** Сеть растёт как дерево; следующий дом может подключиться к уже принятому отводу. Общий участок оплачивается один раз, расход, ДУ и камеры пересчитываются.
9. **Факт на карте.** Полный API-прогон v28 подключил 14/17; статус `PARTIAL`. Экспорт проверен по ID, топологии, конечным точкам, суммам и согласованию с API; геометрические нормы проверяет серверный валидатор.
10. **Экономика.** Строительство 333,378 млн ₽, штраф 338,995 млн ₽, итог 672,373 млн ₽. За каждую отсутствующую точку начисляется `100 000 000 + 500 000 × flow_tph` ₽; `unsearched` не исключает штраф.
11. **Три оставшиеся цели.** По 2/5/10 показать свободный просвет против требуемого отступа, ближайший ввод из §2.2 приложения, запрет повторного пересечения ОКС из таблицы 2 и замкнутый двор цели 5. Другие фасады локально свободны, но не соответствуют буквальному правилу ближайшей границы. Основное ТЗ, §2.9, утверждает подключаемость всех зданий, поэтому нужен ответ организаторов; ненайденный маршрут не объявлять невозможным.
12. **Развитие.** Уточнение правила ввода, расширение поиска и инженерный контур.
13. **Статус и демо.** 14/17 — полный API-результат; 17/17 — конкурсный критерий, пока не подтверждён.

Живой показ проводить по [сценарию](demo.md). Проверенный экспорт v28 хранится только локально и не включён в публичный Git вместе с конкурсными данными; его можно повторно получить через API после собственного прогона. Прежний `artifacts/demo/heat-network-variants.geojson` относится к более ранней версии.
